\section{Graphs, from scratch}\label{app:graphs}

The few terms of graph theory that the note uses, each with the place where it is used.

\begin{itemize}
  \item \textbf{Graph.} A set of \emph{nodes} and a set of \emph{edges}, each edge joining two
        nodes. The active graph $G(t)$ of Section~\ref{sec:configurations} has a node for each flight
        and an edge for each pair interval in progress.
  \item \textbf{Path.} A sequence of nodes, each joined by an edge to the next. Two nodes are
        \emph{connected} when a path joins them.
  \item \textbf{Connected component.} A largest set of nodes connected to each other. Every node is
        in exactly one component; a node with no edge is a component alone (a pilot flying solo).
        A configuration is a component with at least two nodes, with its edges.
\end{itemize}

Two members of a configuration need not share an edge: in the chain 1--2--3 of
Figure~\ref{fig:graph}, pilots 1 and 3 are in the same configuration through pilot 2.

\begin{itemize}
  \item \textbf{Directed graph.} The edges carry an arrow. For the episodes the nodes are
        groups, with an arrow $g\to g'$ when $g'$ starts as $g$ ends and they share a member
        (Section~\ref{sec:episodes}). An episode is a connected component of this graph, arrows
        ignored.
  \item \textbf{Bipartite graph.} Nodes of two kinds, edges only between kinds. At one instant, the
        groups ending and those starting, with an edge when they share a member. Each
        component is one event (Figure~\ref{fig:events}); its outcome follows from how many
        groups it has on each side: one to one is a join or a leave (members added or
        removed), one to several a split, several to one a merge (Section~\ref{sec:describe}).
\end{itemize}

\paragraph{Shape} (Section~\ref{sec:chains}). For a connected graph of $n$ nodes and $m$ edges:
\begin{itemize}
  \item \textbf{Density} $m/\binom{n}{2}$: the share of the node pairs joined by an edge.
  \item \textbf{Distance} between two nodes: the fewest edges of a path joining them.
        \textbf{Diameter}: the largest distance. In the chain 1--2--3 the diameter is 2; in a
        triangle, 1.
  \item \textbf{Complete graph}: every pair joined, density 1, diameter 1. \textbf{Tree}: $m=n-1$,
        the fewest edges that keep $n$ nodes connected, with no closed path; a \emph{chain} is a tree
        with diameter $n-1$, a \emph{star} one with diameter 2.
\end{itemize}

\paragraph{Order} (Section~\ref{sec:leaders}). In a directed graph:
\begin{itemize}
  \item a \textbf{cycle} is a path that follows the arrows back to its start (A$\to$B$\to$C$\to$A);
        a graph with none is \textbf{acyclic}, and its nodes can be put in a line with every arrow
        pointing forward;
  \item a \textbf{source} has no arrow coming in: here, a pilot with nobody ahead, a leader;
  \item the \textbf{depth} of an acyclic graph is its longest chain of arrows: 1 for a star, $n-1$
        for a line.
\end{itemize}
A directed triangle is \emph{transitive} (A$\to$B, B$\to$C, A$\to$C) or \emph{cyclic}; with arrows
drawn at random, 2 of its 8 orientations are cyclic.

\paragraph{Configuration model} (Section~\ref{sec:partners}). A random graph with the
\emph{degrees} (the number of edges of each node) of a given one: each node gets as many half-edges
as its degree, and the half-edges are paired at random~\cite{newman2010}. It keeps how many
partners each pilot had and changes only who they were.
